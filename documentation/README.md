# Documentation Hub — Meta-Innovation Harness

The complete, organized documentation set for the Meta-Innovation Harness. Start here, then
follow the map below to the layer you need.

> **One-line definition.** A layered set of Claude Code skills that orchestrate four
> browser-driven frontier LLMs (Claude · ChatGPT · Gemini · Grok) through Claude-in-Chrome to
> run a "blanking + leaking" collective-genius method on *any* research goal — with every
> interaction archived for absolute transparency.
