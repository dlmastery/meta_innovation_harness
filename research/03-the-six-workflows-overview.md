# The Six Innovation Harness Workflows — Overview

This is a concise reference for all six fully autonomous workflows (named "Innovation Harnesses"). Each workflow is a production-grade AI swarm orchestrated by a single Orchestrator AI. The four Super Expert AIs always carry fixed roles:

| AI | Permanent Role |
|----|---------------|
| **Claude** | Polymath Philosopher + Biology + Ancient Texts |
| **GPT** | Physics + Chemistry + Rigorous Engineering |
| **Gemini** | Social Sciences + Product + Evaluation Systems |
| **Grok** | Creative Synthesis + World Modeling + Radical Efficiency |

The six questions addressed by every workflow:

- **Q1**: Truly self-learning / organic continuously learning architectures?
- **Q2**: Reliable long-duration autonomous agents (days-long)?
- **Q3**: Right evaluation paradigm beyond benchmarks?
- **Q4**: Closing the human-AI efficiency gap?
- **Q5**: Advancing world modeling / physical dynamics (Gemini Omni)?
- **Q6**: One foundational model powering thousands of specialized products?

Full master orchestrator prompts (copy-paste ready) are in [`source/metainnovation-original.md`](source/metainnovation-original.md), Tabs 16–22. The meta-meta and Tsaheylu-infused version of Workflow 2 is documented in [04-meta-meta-and-tsaheylu.md](04-meta-meta-and-tsaheylu.md).

## Key Design Elements Shared by All Six Workflows

- **Clean-slate blanking**: The focal question's own prior answers are completely deleted before each regeneration. The AI derives fresh, informed by the other questions' answers only.
- **Leaking**: All other questions' current best answers are provided as context.
- **Four AI responses per focal question per round**: Each of Claude, GPT, Gemini, and Grok responds independently.
- **Orchestrator selection**: After each inner loop, the Orchestrator selects (or lightly synthesizes) the single strongest response as the new "Current Best."
- **Distillation pass**: After each inner loop (or outer round, depending on workflow), a short synthesis identifies the strongest new cross-connection.
- **Final convergence**: All workflows end with a unified synthesis across all six questions.

## Recommended Starting Point

**Workflow 2 (TSM-CI Kitchen Table)** is the recommended first harness. It is the closest match to what the actual DeepMind leaders described doing — the long-shared-history, "finish each other's sentences" dynamic — and explicitly maintains all three transactive systems (TMS/TAS/TRS).
